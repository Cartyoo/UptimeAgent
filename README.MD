# Layeredy Uptime Agent for Minecraft
UptimeAgent allows you to bring [Layeredy Uptime](https://lyrdy.co/uptime) server monitoring to your Minecraft server!

## Features
 - Configurable statistic report timing (60s minimum)
 - Full support for all features supported by the [Official Server Agent](https://docs.layeredy.com/server-agent), but for your Minecraft server rather than a Linux/macOS/Windows machine:
   - CPU Usage Percentage
   - Server Uptime
   - System Hostname (usually a UUID for Docker)
   - Server Total Memory & Memory Usage
   - IP Address
   - Server Total Disk & Used Disk (machine-wide for Docker)
   - Operating System
   - CPU Model, Cores, and Threads (machine-wide for Docker)
   - Agent Version
   - Metrics for CPU, Memory, and Disk Usage in the Dashboard
   - Last Report Time
